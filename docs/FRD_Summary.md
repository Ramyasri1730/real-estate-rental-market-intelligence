SECTION 2: FUNCTIONAL REQUIREMENT DOCUMENT (FRD)
2.1 Functional Overview 
The system provides an interactive Business Intelligence dashboard that
enables users to analyse Abu Dhabi rental property data.

The solution combines data preparation, SQL analysis, and Power BI
visualization to deliver actionable insights.
--------------------------------------------------------------------------------------------------------------------------------------
2.2 Data Requirements 
The dashboard uses rental property data containing:
-   Property Address
-   City
-   Location
-   Property Type
-   Bedrooms
-   Bathrooms
-   Area (Sqft)
-   Annual Rent
-   Rent per Sqft
-   Furnishing Status
-   Listing Age
-   Latitude
-   Longitude
--------------------------------------------------------------------------------------------------------------------------------------
    2.3 Dashboard Requirements 
    2.3.1 Executive Dashboard 
    Features:
-   Total Portfolio Value
-   Average Annual Rent
-   Total Active Listings
-   Average Rent per Sqft
-   Demand Indicators
-   KPI Monitoring
--------------------------------------------------------------------------------------------------------------------------------------
    2.3.2 Location Intelligence Dashboard 
    Features:
-   Geographic rental analysis
-   Location performance comparison
-   High-demand areas identification
-   Rental distribution by community
--------------------------------------------------------------------------------------------------------------------------------------
    2.3.3 Rental Analysis Dashboard 
    Features:
-   Rental price comparison
-   Property type analysis
-   Bedroom and area analysis
-   Furnishing impact analysis
-   Listing age analysis
--------------------------------------------------------------------------------------------------------------------------------------
    2.4 Data Processing Requirements 
    The solution should support:
-   Data cleaning
-   Data transformation
-   Data validation
-   Data quality checks
-   Data modeling
--------------------------------------------------------------------------------------------------------------------------------------
    2.5 Technical Requirements 
    Tools Used:
-   Microsoft Excel
-   SQL Server
-   Power BI
-   DAX
-   GitHub
--------------------------------------------------------------------------------------------------------------------------------------
    2.6 User Requirements
    Users should be able to:
-   Filter data interactively
-   Compare properties
-   Analyze rental trends
-   Identify investment opportunities
-   Export insights for decision-making

    2.8 Success Criteria
