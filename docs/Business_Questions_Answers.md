# Business Questions & Analysis Answers


## 1. Which locations have the highest rental demand?

Rental demand was analyzed using:

- Number of active listings
- Average rental values
- Listing age
- Demand indicators


## 2. What factors influence rental pricing?

Rental prices are influenced by:

- Location
- Property type
- Area size
- Number of bedrooms
- Furnishing status


## 3. Which properties provide better investment opportunities?

Investment opportunities were evaluated using:

- Rent per Sqft
- Rental efficiency
- Demand indicators
- Property location


## 4. How does rental price vary across Dubai communities?

Rental prices vary based on:

- Community popularity
- Property size
- Property type
- Market demand


# Key Insights

- Identified high-performing rental locations.
- Compared rental efficiency using Rent per Sqft.
- Detected slow-moving listings.
- Supported investment decisions through Power BI dashboards.
