# Business Requirement Document (BRD)

## Project Name

Rental Market Intelligence & Investment Decision Framework


## Project Overview

This project analyzes UAE rental property data using Excel, SQL Server, and Power BI to support investment decisions.


## Business Objectives

- Analyze rental trends
- Identify high-performing locations
- Measure rental efficiency
- Support investment decisions


## Stakeholders

- Real Estate Investors
- Property Managers
- Consultants
- Decision Makers


## Business Requirements

- Rental analysis
- Location analysis
- KPI dashboards
- Investment insights
