# Functional Requirement Document (FRD)

## Dashboard Requirements

The solution should provide:

- Executive Dashboard
- Location Intelligence Dashboard
- Rental Analysis Dashboard


## Data Requirements

The dataset includes:

- Property Type
- Location
- Bedrooms
- Bathrooms
- Area
- Annual Rent
- Rent per Sqft
- Furnishing Status


## Technical Requirements

Tools:

- Excel
- SQL Server
- Power BI
- DAX
- GitHub
